# Make10 (Web版)

HTML/CSS/JavaScript だけで作った、4つの数字から10を作るパズルゲームです。スマホでも遊べます（PWA）。

## 遊び方

1. ランダムに出題される4つの数字を**すべて1回ずつ**使う。
2. ＋（たす）・－（ひく）・×（かける）・÷（わる）と括弧を自由に組み合わせて、計算結果がちょうど **10** になる式を作る。
3. 数字タイルをタップすると式に追加され、演算子・括弧ボタンも同様にタップで入力。⌫で1つ戻す、Cで全部やり直し。
4. すべての数字を使い、括弧が閉じている状態になると「＝10 で決定」が押せるようになります。

出題される4つの数字は、**必ず10を作れる組み合わせだけ**が選ばれるようになっています（内部でソルバーが解の存在を確認してから出題）。

## モード

- **一人用（スピード）**: 設定した問題数（5/10/15/20問）を、できるだけ速く解く自己ベスト更新モード。合計タイムが端末に保存され、次回以降と比較できます。ヒントを使うとその回はベスト記録の対象外になります。
- **複数人対戦（オンライン）**: 同じ問題セットを複数端末が同時に解き、先に全問クリアした人が優勝のリアルタイム対戦モード（要Firebase設定。下記「オンライン対戦の準備」を参照）。

設定は端末に保存され、次回起動時も引き継がれます。

## iPhone で試す方法

このアプリはブラウザだけで動く静的なファイル一式です。`index.html` を直接ダブルクリックして開くと、ブラウザのセキュリティ制限で `script.js` の読み込みがブロックされて動かないため、**簡易サーバー経由で開く**必要があります。

### 同じWi-Fi内のiPhoneで動作確認する場合

1. PCでこのフォルダに移動してサーバーを起動します。

```bash
python -m http.server 8000
```

2. PCのIPアドレスを確認します（例: `192.168.1.23`）。
3. iPhoneを同じWi-Fiに接続し、Safariで `http://192.168.1.23:8000/index.html` を開きます。
4. 共有ボタン → 「ホーム画面に追加」でアプリのように使えます。

### 常時使えるようにしたい場合

GitHub Pages / Netlify / Vercel などの無料ホスティングに `make10_app` フォルダの中身をアップロードすると、HTTPSのURLが発行され、いつでもアクセスしてホーム画面に追加できます。

## オンライン対戦の準備（Firebase設定）

複数人対戦モードは、複数端末の状態をリアルタイムで同期するために無料の Firebase Realtime Database を使います。`firebase-config.js` に設定値を入力するまでは、複数人対戦を選ぶと「Firebaseが未設定です」という案内が表示されるだけで、他のモードには影響しません。

1. [Firebase コンソール](https://console.firebase.google.com/) にGoogleアカウントでログインし、「プロジェクトを作成」。名前は任意（例: `make10-multi`）。Googleアナリティクスは無効でOK。
2. 左メニュー「構築」→「Realtime Database」→「データベースを作成」。ロケーションは任意（例: `asia-southeast1`）。セキュリティルールは一旦「テストモード」で作成。
3. 作成後、「ルール」タブを開き、次の内容に置き換えて「公開」。テストモードは30日で失効するため、これで恒久的に `rooms` 以下だけ誰でも読み書きできる状態にします。

```json
{
  "rules": {
    "rooms": {
      ".read": true,
      ".write": true
    }
  }
}
```

> ⚠️ この設定は認証なしで誰でも読み書きできる簡易的なものです。ルームコードを知っている人（またはFirebaseの設定値を知っている人）は理論上どのルームのデータも閲覧・書き換えできます。友人・家族などの信頼できる相手と遊ぶ前提の実装であり、不特定多数に公開する用途には向きません。

4. 左メニューの⚙️「プロジェクトの設定」→「全般」タブ→ 下部の「マイアプリ」→ `</>`（ウェブ）アイコンでウェブアプリを登録（Firebase Hostingのチェックは不要）。
5. 表示される `firebaseConfig` の値（apiKey / authDomain / databaseURL / projectId / storageBucket / messagingSenderId / appId）を、このフォルダの [`firebase-config.js`](firebase-config.js) の対応する `"PASTE_ME"` の部分にそれぞれ貼り付けて保存します。

設定後は、複数の端末（またはブラウザタブ）で同じURLを開き、1人が「ルームを作成」→表示された4文字のコードを他の参加者に伝えて「ルームに参加」してもらうことで対戦できます。ホストが「ゲーム開始」を押すと同じ問題セットが全員に配られ、各自のペースで解いていき、先に全問クリアした人が優勝です。画面上部に全員の進捗（◯/◯問）がリアルタイムで表示されます。

## ゲームロジックについて

- 数字は0〜9からランダムに4つ選ばれます（重複あり）。
- 「10が作れる組み合わせだけ出題する」ための判定・入力式の採点は、すべて分数（BigInt）で厳密に計算しており、浮動小数点の誤差は発生しません。
- 0による割り算など評価できない式を決定しようとした場合は、その場でエラーメッセージを表示し、式を修正できます。
