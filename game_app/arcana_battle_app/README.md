# アルカナバトル

一人用のTCG風カードバトルゲームです。CPUと1対1で対戦します。

## 遊び方

```bash
python -m http.server 8125 --directory game_app/arcana_battle_app
```

ブラウザで `http://localhost:8125` を開いてください。

## 機能

- **スタンダードデッキ**: 24種類のカードを最初から使用可能
- **拡張パック「焔の書」**: ゴールドでパックを購入し、新しいカードを集める（コモン/レア/エピック/レジェンダリー）
- **デッキ構築**: 20枚（同名カードは2枚まで）でデッキを編成
- **対戦**: CPU相手にライフ20・マナ最大10のターン制バトル
- **ゲーム内通貨**: 対戦報酬（勝利+25G/敗北+5G）とデイリーボーナス（+50G）でゴールドを獲得し、パック購入に使う

## ルール概要

- 毎ターン最大マナが+1（上限10）され、マナは全回復
- ミニオンを場に出して攻撃、スペルでダメージ・回復・ドローなどの効果
- キーワード: 挑発（先に攻撃を受ける）・速攻（出したターンに攻撃可）・吸血（与えたダメージ分回復）
- 相手のライフを0にすれば勝利

## データ保存

ゴールド・コレクション・デッキ・戦績は `localStorage` に保存されます（`arcanabattle.state.v1`）。
