# デュエルマスターズ 第1弾再現アプリ — 開発メモ

## 概要
実在のTCG「デュエルマスターズ」のコアルールを再現した、ひとり用(CPU対戦)のブラウザゲーム。
`game_app/*` の他アプリ(灰の塔・アルカナバトル等)と同じ vanilla JS ES modules・ビルドレス構成。
ライブ: `https://bhag008.github.io/game_app/duel_masters_app/`

## カードプールについて
`js/cards.js` は2002年発売の実際の第1弾(DM-01)の**全120種**(SR10/VR10/R30/UC30/C40)を、
公式カードデータベース(dm.takaratomy.co.jp)とファンWiki(dmwiki.net/DM-01、各カード個別ページ)を
調査エージェント経由で参照し、カード名・文明・コスト・パワー・種族・ルールテキストをそのまま再現したもの。
- イラストは著作権上の理由から実装していない(テキスト+文明カラーのカード表示)
- 数枚(クリムゾン・ワイバーン、爆勇士ユーカーン、捕らえる者ボーン・スパイダー、走神兵ウルヘリオン、
  ガイアズ・ソング、ブラッディ・イヤリング、鋼鉄の鎚)は初回調査で情報が曖昧だったため個別に再調査済み
- 第1弾には多色カード・進化クリーチャーは存在しない
- カードリストの誤りが見つかった場合は `js/cards.js` の `CARD_DB` を直接修正すればよい(データ駆動)

## アーキテクチャ
- `js/state.js` — `nextUid`、デッキ(`duelmasters.decks.v1`)と戦績(`duelmasters.meta.v1`)の localStorage 永続化
- `js/cards.js` — カードDB(120種)、文明定義、キーワード能力ヘルパー(`hasKeyword`/`keywordValue`)、
  効果ファクトリ関数群(destroyEnemyOne/bounceAny/tapEnemy/deckTutor 等)、デッキ検証
- `js/engine.js` — `DuelEngine` クラス。ターン進行、マナ支払い(文明1致+残りは任意)、召喚酔い、
  攻撃対象制限(相手クリーチャーは原則タップ状態のみ攻撃可、アンタップキラー/一時許可で例外)、
  ブロック可否判定(ブロックされない/パワー条件付きブロック不可を考慮)、バトル解決(スレイヤー・
  バトル後自壊などのキーワードを含む)、シールドブレイクとS・トリガーのキュー管理、
  CIP(クリーチャーが出た時)能力の「先に出してから対象を選ぶ」実タイミング再現(`pendingCip`)
- `js/ai.js` — CPUの意思決定:
  - `cpuTurnSteps(engine)`: CPUの1ターンを1アクションずつ進めるジェネレータ
  - `chooseTargetsForCpu` / `sortCandidates`: 効果の対象を種類(敵クリーチャー破壊は強い方から、
    自分クリーチャーの生贄は弱い方から、等)に応じて自動選択
  - `chooseBlockForCPU` / `autoResolveShieldTriggers`: プレイヤーの手番中にCPU側が行う判断を同期的に返す
- `js/decks.js` — CPU用プリセットデッキ(各文明24種をレアリティ別の採用枚数で40枚以上に構築、モノカラー5種)
- `js/main.js` — 画面遷移・DOM描画・対象選択モーダル(`promptTargetSelection`、min/max件まで逐次選択)

## ルール実装上の設計判断・簡略化
- シールドは自分の分も含めて内容を伏せて表示。ブレイクされて初めて中身が分かる
- クリーチャーを攻撃対象にできるのは原則タップ状態のもののみ(実際のルール通り)。
  アンタップキラー系キーワードや、対象許可を与える一時効果(カオス・ストライク等)は例外として実装
- ブロックされた場合はシールドは減らず、攻撃側と防御側がパワー比較でバトルするのみ
- シールドブレイクで手札に加わったカードの所有者は防御側。S・トリガーは防御側が無償使用するか選べる
- パワーアタッカー/条件付きパワー上昇は「攻撃中のみ」か「常時」かをキーワードごとに区別して実装
- スレイヤーは「相手を戦闘結果に関わらず破壊」、バトル後自壊は「結果に関わらず自分も破壊」として実装
- マナゾーンのタップ対象・マナ送りの対象カードは自動選択(どの札でも実質等価なため)
- 「相手が自分のクリーチャーを選ぶ」効果(腐食虫スワンプワーム等、3種のみ)は簡略化のため、
  常に一番パワーが低い自分のクリーチャーを自動選択する(対象自体は正確、選ぶ主体だけ簡略化)
- 手札を見ずに選ぶハンデス(嘲りの影マスクド・ホラー、ゴースト・タッチ)は完全ランダムで自動解決
- 山札を見て1枚加える系(真理の伝道師レイーラ、クリスタル・メモリー、ディメンジョン・ゲート)は
  実際の山札全体から検索するモーダルを実装(該当なしまたは0枚選択も可)

## 未実装/今後の拡張候補
- クラウド同期、ローカル2人対戦は今回スコープ外(灰の塔と同様の判断)
- CPUデッキは現状モノカラー5種のみ。多色デッキや難易度差のあるCPUの追加は容易(`js/decks.js`)
- 「相手が自分のクリーチャーを選ぶ」効果を実際に相手側(人間プレイヤーの番)で選ばせるインタラクティブ化

## 動作確認手順
`.claude/launch.json` の `duel_masters` エントリ(ポート8129)でプレビュー可能。デッキ編成→CPU選択→対戦の
一連の流れと、マナチャージ/召喚酔い/タップ状態のみ攻撃可能/ブロッカー/シールドブレイク/W・ブレイカー/
S・トリガー(対象選択含む)/CIP能力(対象あり・なし)/山札タトラー/ダイレクトアタック勝敗をブラウザで
確認済み。テスト中、バウンス系「anyCreature」対象でCPUが自分のクリーチャーまで戻してしまう不具合を
発見し `js/ai.js` で修正済み(相手側のみを対象にするよう限定)。
