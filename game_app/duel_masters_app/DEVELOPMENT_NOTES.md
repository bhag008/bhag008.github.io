# デュエルマスターズ 第1弾再現アプリ — 開発メモ

## 概要
実在のTCG「デュエルマスターズ」のコアルールを再現した、ひとり用(CPU対戦)のブラウザゲーム。
`game_app/*` の他アプリ(灰の塔・アルカナバトル等)と同じ vanilla JS ES modules・ビルドレス構成。
ライブ: `https://bhag008.github.io/game_app/duel_masters_app/`

## カードプールについて(重要)
`js/cards.js` のカード名・パラメータ・効果テキストは、2002年発売の実際の第1弾の**記憶ベースのベストエフォート再現**であり、正確性は保証されていない。
- ボルシャック・ドラゴン、紅蓮の弓矢、デーモン・ハンド、アクア・サーファー、ホーリー・スパーク、知識の光 は実在カードの記憶に基づく再現(名称・大枠の効果は概ね一致している想定)。
- それ以外の多くのカードは「当時の雰囲気に合わせた創作」で、実在の第1弾カードと名称・数値が一致しない可能性が高い。
- 多色カードや進化クリーチャーは第1弾に存在しないという記憶に基づき未実装。
- 正確なカードリストが分かった場合は `js/cards.js` の `CARD_DB` を差し替えるだけで反映される(構造はデータ駆動)。

## アーキテクチャ
- `js/state.js` — `nextUid`、デッキ(`duelmasters.decks.v1`)と戦績(`duelmasters.meta.v1`)の localStorage 永続化
- `js/cards.js` — カードDB、文明定義、効果タイプの定義、デッキ検証(40枚以上・同名4枚まで)
- `js/engine.js` — `DuelEngine` クラス。ターン進行(アンタップ→ドロー→メイン→アタック→終了)、マナ支払い(コスト分のマナをタップ、うち1枚は文明が一致する必要あり)、召喚酔い、攻撃/ブロック解決(パワー比較でバトル、負けた方を破壊、同数は相打ち)、シールドブレイク、S・トリガーのキュー管理、山札切れによる敗北判定
- `js/ai.js` — CPUの意思決定:
  - `cpuTurnSteps(engine)`: CPUの1ターンを1アクションずつ進めるジェネレータ。`main.js` が `next()` を呼ぶたびに再描画し、`engine.pendingBlock` や `engine.pendingShieldTriggers`(手番プレイヤー側)が立った場合はプレイヤーの入力を待ってから次の `next()` を呼ぶ
  - `chooseBlockForCPU` / `autoResolveShieldTriggers`: プレイヤーの手番中にCPU側が行うブロック判断・S・トリガー使用判断を同期的に返す(プレイヤー手番ではCPUの意思決定に待ち時間を作らない設計)
- `js/decks.js` — CPU用プリセットデッキ(各文明の全10種を4枚ずつ、ちょうど40枚のモノカラーデッキを5つ)
- `js/main.js` — 画面遷移(タイトル/デッキ編成/CPU選択/対戦/リザルト)とDOM描画、全てのユーザー操作のワイヤリング。フレームワーク不使用

## ルール実装上の設計判断
- シールドは自分の分も含めて内容を伏せて表示(枚数のみ)。ブレイクされて初めて中身が分かる — 実際のルール通り
- ブロックされた場合、シールドは減らず攻撃側と防御側クリーチャーがパワー比較でバトルするのみ(直接ダメージという概念は無い)
- クリーチャーを対象に攻撃した場合、ブロックが無ければその対象クリーチャーと直接バトルする(タップ状態は問わない)
- シールドブレイクで手札に加わったカードの所有者は防御側(攻撃を受けた側)。S・トリガーはその防御側が無償で使うかどうかを選べる
- マナゾーンのタップ対象は自動選択(どのマナ札をタップしても差はないため、プレイヤーに選ばせる意味が無い= 簡略化ではなく実質的に等価)
- 手札破壊(闇の掌握)は捨てるカードを「捨てる側」が選ぶ(CPUはコスト最小のカードを選択、プレイヤーはモーダルで選択)

## 未実装/今後の拡張候補
- クラウド同期、ローカル2人対戦は今回スコープ外(灰の塔と同様の判断)
- CPUデッキは現状モノカラー5種のみ。多色デッキや難易度差のあるCPUの追加は容易(`js/decks.js` にエントリを足すだけ)
- カードプールの拡充・訂正は `js/cards.js` の `CARD_DB` を編集するだけで自動的にデッキ編成/バトル両方に反映される

## 動作確認手順
`.claude/launch.json` の `duel_masters` エントリ(ポート8129)でプレビュー可能。デッキ編成→CPU選択→対戦の一連の流れと、マナチャージ/召喚酔い/ブロッカー/シールドブレイク/S・トリガー/W・ブレイカー/ダイレクトアタック勝利をブラウザで確認済み(詳細は開発時のセッションログ参照)。
