# ヒット＆ブロー (Web版)

HTML/CSS/JavaScript だけで作った、スマホでも遊べるヒットアンドブローです。iPhone の Safari で開いてホーム画面に追加すればアプリのように使えます（PWA）。

## 遊び方

1. 出題される数字を、決めた桁数だけ当てる。
2. 「Hit」= 数字も位置も合っている桁数、「Blow」= 数字は合っているが位置が違う桁数。
3. すべて Hit になったらクリア。

## 設定できること

- **出題モード**
  - 自動（ランダム）: コンピュータが数字を自動で決める（デフォルト）
  - 手動（自分で入力）: 出題者が数字を伏せ字で入力し、画面を回答者に渡して遊ぶ2人プレイ用モード
  - オンライン対戦（複数端末）: 各自のスマホからルームに参加し、システムが決めた共通の数字を順番に推理していくタイムアタック方式。先に正解した人の勝ち（要Firebase設定。下記「オンライン対戦の準備」を参照）
- 桁数（3〜5桁）
- 使用する数字の範囲（例: 0〜9、1〜6 など好きな範囲に変更可能）
- 数字の重複を許可するかどうか
- **制限時間**（任意の分・秒）: 画面上部に残り時間をカウントダウン表示するストップウォッチが出ます。0になっても強制終了はせず、00:00のまま赤く点滅して知らせるだけなので、そのまま続けて遊べます。設定でオフにもできます。1回回答するたびに制限時間いっぱいにリセットされ、再カウントダウンが始まります（正解した場合はリセットせずそのまま停止）。

設定は端末に保存され、次回起動時も引き継がれます。

アプリを開くと、まず設定画面が表示されます。内容を確認・変更して「保存して新規開始」を押すか、そのまま「キャンセル」で閉じてもゲームが始まります。

ゲームは「スタート」ボタンを押すまで始まりません。自動モードでは新しいゲームのたびにスタート画面が表示され、押した瞬間にタイマーもゲームも同時に開始します（手動モードは、出題者が数字を入力した後の「スタート」ボタンが同じ役割です）。

## iPhone で試す方法

このアプリはブラウザだけで動く静的なファイル一式（`index.html` / `style.css` / `script.js` / `manifest.json`）です。`index.html` を直接ダブルクリックして開くと、ブラウザのセキュリティ制限で `script.js` の読み込みがブロックされて動かないため、**簡易サーバー経由で開く**必要があります。

### 同じWi-Fi内のiPhoneで動作確認する場合

1. PCでこのフォルダに移動してサーバーを起動します。

```bash
python -m http.server 8000
```

2. PCのIPアドレスを確認します（例: `192.168.1.23`）。
3. iPhoneを同じWi-Fiに接続し、Safariで `http://192.168.1.23:8000/index.html` を開きます。
4. 共有ボタン → 「ホーム画面に追加」でアプリのように使えます。

### 常時使えるようにしたい場合

GitHub Pages / Netlify / Vercel などの無料ホスティングに `hit_and_blow_app` フォルダの中身をアップロードすると、HTTPSのURLが発行され、いつでもiPhoneからアクセスしてホーム画面に追加できます。

## オンライン対戦の準備（Firebase設定）

オンライン対戦モードは、複数端末の状態をリアルタイムで同期するために無料の Firebase Realtime Database を使います。`firebase-config.js` に設定値を入力するまでは、オンライン対戦を選ぶと「Firebaseが未設定です」という案内が表示されるだけで、他のモードには影響しません。

1. [Firebase コンソール](https://console.firebase.google.com/) にGoogleアカウントでログインし、「プロジェクトを作成」。名前は任意（例: `hit-and-blow-multi`）。Googleアナリティクスは無効でOK。
2. 左メニュー「構築」→「Realtime Database」→「データベースを作成」。ロケーションは任意（例: `asia-southeast1`）。セキュリティルールは一旦「テストモード」で作成。
3. 作成後、「ルール」タブを開き、次の内容に置き換えて「公開」。テストモードは30日で失効するため、これで恒久的に `rooms` 以下だけ誰でも読み書きできる状態にします。

```json
{
  "rules": {
    "rooms": {
      ".read": true,
      ".write": true
    }
  }
}
```

> ⚠️ この設定は認証なしで誰でも読み書きできる簡易的なものです。ルームコードを知っている人（またはFirebaseの設定値を知っている人）は理論上どのルームのデータも閲覧・書き換えできます。友人・家族などの信頼できる相手と遊ぶ前提の実装であり、不特定多数に公開する用途には向きません。

4. 左メニューの⚙️「プロジェクトの設定」→「全般」タブ→ 下部の「マイアプリ」→ `</>`（ウェブ）アイコンでウェブアプリを登録（Firebase Hostingのチェックは不要）。
5. 表示される `firebaseConfig` の値（apiKey / authDomain / databaseURL / projectId / storageBucket / messagingSenderId / appId）を、このフォルダの [`firebase-config.js`](firebase-config.js) の対応する `"PASTE_ME"` の部分にそれぞれ貼り付けて保存します。

設定後は、複数の端末（またはブラウザタブ）で同じURLを開き、1人が「ルームを作成」→表示された4文字のコードを他の参加者に伝えて「ルームに参加」してもらうことで対戦できます。ホストが「ゲーム開始」を押すとタイムアタックが始まり、画面下のプレイヤー一覧で誰の番かが分かります。
